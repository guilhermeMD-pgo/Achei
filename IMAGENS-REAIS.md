# Logos e fotos reais

O site ja usa automaticamente qualquer arquivo colocado nas pastas abaixo.
Nao precisa mexer em codigo. Depois de copiar, recarregue a pagina.
Para conferir o que falta, rode: `npm run imagens:check`

Dicas:
- Foto quadrada (1:1), ao menos 600x600 px, produto centralizado.
- Fundo branco ou transparente (PNG) fica melhor nos dois temas.
- Fotos de banco gratuito com licenca livre: Unsplash, Pexels, Pixabay.
  Para marcas especificas (ex.: combo do McDonald's), peça a foto a propria loja.
- Prefira arquivos com menos de 300 KB (use squoosh.app para reduzir).

Se o arquivo nao existir, o site mostra a ilustracao no lugar.
